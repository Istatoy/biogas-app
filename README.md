# Smartbiogas

**Smartbiogas** — это веб-приложение для мониторинга, управления и аналитики биогазовых установок. Система позволяет операторам и администраторам в реальном времени отслеживать параметры работы установки, управлять приборами и получать отчёты.

## Основные возможности

- **Аутентификация и роли**  
  Вход по JWT-токену, разграничение доступа: администратор, оператор, читатель.
- **Управление пользователями и устройствами**  
  Добавление/удаление пользователей, назначение ролей. Регистрация и привязка сенсоров, регуляторов, насосов.
- **Дашборд в реальном времени**  
  Графики и цифровые индикаторы уровня биогаза, температуры, давления, влажности и других параметров.
- **Карта объектов**  
  Отображение геолокации всех установок на интерактивной карте Google Maps API.
- **Таблица данных**  
  Гибкая таблица с фильтрацией, сортировкой и пагинацией на базе React Table.
- **Отчёты и экспорт**  
  Генерация ежедневных, недельных и годовых отчётов; экспорт данных в форматы CSV и Excel.
- **Уведомления и тревоги**  
  Настраиваемые пороговые значения: аварийные оповещения по e-mail или SMS.

## Технологический стек

- **Фронтенд**:  
  React + Tailwind CSS (или Material UI), React Router, React Table  
  Google Maps API для геоинформации  
- **Бэкенд**:  
  Node.js + Express (REST API)  
  MySQL — хранение пользователей, устройств и собранных данных  
- **Авторизация**:  
  JWT (JSON Web Tokens)  
- **Сбор данных**:  
  WebSocket / периодический опрос внешних API от устройств  
- **Инструменты разработки**:  
  ESLint, Prettier, Husky (git-хуки), Docker (опционально)
